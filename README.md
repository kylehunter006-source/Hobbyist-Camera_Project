# Hobbyist-Camera_Project
  This repo was initially made to demonstrate the camera I made in week for a robotics club I was applying for. It was my first parametric model that taught me think of how the different pieces would need to move together to produce a camera that could move in every direction. It has now changed into a personal project that I thought i could improve and implement on other project should I iron out many of the problems that came from the initial draft.

  If your curious as to what the camera initially looked like in my week long modeling march you can look in the tmr project folder. What the camera looks like now can be found in the 2.0 folders.
